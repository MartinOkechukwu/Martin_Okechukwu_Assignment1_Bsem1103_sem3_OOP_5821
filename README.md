## Patient Record Management System

## Project Information
- Course: PROG211 - Object-Oriented Programming 1
- Institution: Limkokwing University of Creative Technology,
  Sierra Leone
- Language: Python
- Domain: Health
- SDG: SDG 3 - Good Health and Well-being

## Project Description
The Patient Record Management System is a Python program that
demonstrates how Object-Oriented Programming can help a clinic
organize basic patient information.

Users can register patients, display records, search by patient
ID, update records, and count registered patients.

## Features
1. Register patients
2. Display all patient records
3. Search by patient ID
4. Update patient information
5. Count registered patients
6. Validate patient age and prevent duplicate IDs

## OOP Concepts
- Classes and objects
- Attributes and methods
- Encapsulation through objects
- Instance methods
- Class methods
- Static methods

## Data Structure
A Python list stores multiple Patient objects.

## DPG Principles
- Open source: source code can be shared and reused.
- Inclusive design: simple text-based interface.
- Privacy: fictional demonstration data only.
- Modular design: separate classes and reusable methods.

## Installation and Usage
1. Install Python 3.
2. Download or clone the repository.
3. Open the project folder in a terminal.
4. Run: python patient_record_system.py

## Example Usage
Sample records:
- P001 - John Kamara
- P002 - Mary Conteh

Choose option 2 to display the records or option 3 to search.

## Limitations
Records are stored in memory and disappear when the program
closes. This is not a production-ready medical records system.
